#  Notebook Todo

An interactive todo planner inspired by paper notebooks and scrapbook journals.

This project is being built as a portfolio pet-project with a focus not only on functionality, but also on the atmosphere of a real physical notebook:
- notebook paper
- stickers
- tape
- handwritten feeling
- pencil interactions
- paper-like animations

---

#  Project Idea

Most todo applications feel like simple tables.

I wanted to create an interface that feels like:
> a personal paper notebook where someone is actually writing things down.

That’s why the project uses:
- notebook style UI
- scrapbook/sticker aesthetic
- paper textures
- handwritten interactions
- slightly imperfect layout rotations
